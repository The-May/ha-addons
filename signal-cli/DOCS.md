## Installation

- Add this repository to the Home Assistant Supervisor Add-on Store
- Choose your desired port - 8080 is default
- Choose your desired options - "normal" is the default one
- Click Start
- RTFM

## How To:

Instructions for use can be found in the official [docs](https://www.home-assistant.io/integrations/signal_messenger/).
This Addon/App behaves identically like the Docker image no fancy stuff, just a "port" to Homeassistant.
Issues should be created there and not here, sice I basically only provide the config.yaml.
