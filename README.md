## Installation

If you want to add the repository manually, follow the instructions on the [Home Assistant website](https://www.home-assistant.io/common-tasks/os#installing-third-party-app-repositories).

Repository URL:

`https://github.com/The-May/ha-addons`

## Add-ons

This repository contains the following apps:

✓ [DB History Plotter](./db_history_plotter/) : Queries HA DB and generates plots as PNG images. Supports MariaDB and SQlite

✓ [Example add-on](./example/) : Example add-on

✓ [OpenHASP Backup](./openhasp_backup/) : Simple Full Backup Tool for OpenHASP.
