1. Download this Addon
2. Setup ftp-user and pass on each plate (must be the same user/pass to keep it simple)
3. Setup single/multiple ip-adresses of your displays (ip adress, not hostname)
4. setup target FTP where this should be saved (works with HA FTP APP (aka Addon)
5. Start Addon, look if something fails, if everything does not fail, you should get a .zip for each Display.


   Note: This Addon always runs once and stops after the Backup-try has been done. So it is normal that this Addon is not running. It should only run when you want to do a full backup.
